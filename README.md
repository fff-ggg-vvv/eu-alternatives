# European Alternatives to US Tech

A curated list of globally available European alternatives to major US software and cloud products, ordered from the biggest and most important systems down to smaller utilities.

Flags show where the company or project is based: 🇪🇺 community project, 🇩🇪 Germany, 🇫🇷 France, 🇨🇭 Switzerland, 🇬🇧 United Kingdom, 🇳🇱 Netherlands, 🇸🇪 Sweden, and so on. Only European companies and projects are listed. Best option first.

| CDN / DNS / edge | Cloudflare, Akamai, Amazon CloudFront | [Bunny.net](https://bunny.net) 🇸🇮, [Gcore](https://gcore.com) 🇱🇺 |
| Web hosting | GoDaddy, Bluehost | [Hostinger](https://www.hostinger.com) 🇱🇹, [IONOS](https://www.ionos.com) 🇩🇪 |
